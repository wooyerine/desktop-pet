# 🐱 Desktop Pet — 픽셀 고양이 동료

데스크탑 화면 위에 떠 있는 큼직한 픽셀의 고양이. 뾰족 귀에 볼 털이 복슬한 회색
고양이가 정면으로 앉아 책상에서 같이 컴퓨터를 합니다. 청키 픽셀 (8px) + 굵은 검정
테두리 스타일이라 어떤 배경화면 위에서도 또렷하게 보여요. 책상 디오라마에 민트
화면 모니터, 키보드, 마우스, 층층이 아이스 커피(생크림+빨대+라떼층)까지 — 소품은
절반 크기 픽셀로 잘게 그려 한눈에 알아볼 수 있고, 타이머는 머리 위 흰 픽셀
말풍선으로 표시됩니다.

- ⌨️ 내가 키보드를 치면 펫도 앞발을 좌우 교대로 콩콩
- 🖱️ 내가 마우스를 움직이면 오른발이 마우스 위로 (둘 다 하면 왼발 키보드 + 오른발 마우스)
- 😴 1분 넘게 가만히 있으면 잠들어요 (Zzz)
- 💢 타이머를 안 쓸 때 키보드를 10분 이상 안 치면 "일해라 냥!" 잔소리 말풍선이 떠요 (타이핑하면 사라짐)
- 🍅 뽀모도로 타이머: 집중 25분 / 휴식 5분 / 커스텀(1~180분), 완료 시 알림 + 펫이 폴짝폴짝 축하

## 실행

```bash
npm install
npm start
```

## macOS 권한

- **키보드 감지**에는 손쉬운 사용 권한이 필요합니다. 첫 실행 시 뜨는 프롬프트에서 허용하거나,
  시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 **Electron**을 켠 뒤 앱을 재시작하세요.
- 권한이 없어도 마우스 움직임은 커서 좌표 폴링으로 감지됩니다 (키보드만 감지 불가).

## 사용법

| 조작 | 동작 |
|---|---|
| 펫(캔버스) 드래그 | 창 위치 이동 |
| ⏰ 버튼 | 타이머 패널 열기/닫기 |
| ✕ 버튼 | 앱 종료 |

창은 항상 위에 떠 있고, 모든 스페이스(전체화면 포함)에서 보이며, Dock에는 나타나지 않습니다.

## 구조

- `main.js` — 투명 창 생성, uiohook 전역 입력 감지(+커서 폴링 폴백), 알림
- `preload.js` — contextBridge IPC
- `pet.js` — 픽셀 아트 스프라이트, 애니메이션 상태 머신, 뽀모도로 타이머
- 고양이는 행별 실루엣(`SIL`)과 색 영역(`PAINT`)으로 정의하고 검정 테두리를 자동
  생성합니다 — 값을 고치면 모양을 바꿀 수 있어요. 눈/발/마우스/컵은 별도 스프라이트

### 디버그

```bash
DEMO=typing npm start        # typing | mousing | sleeping | celebrating | nag
TIMER=25 npm start           # 타이머가 시작된 상태로 실행
SHOT=/tmp/pet.png npm start  # 1.2초 후 스크린샷 찍고 종료
```
