# 🐱 Desktop Pet — 픽셀 고양이 동료

데스크탑 화면 위에 떠 있는 큼직한 픽셀의 고양이. 뾰족 귀에 볼 털이 복슬한 회색
고양이가 정면으로 앉아 책상에서 같이 컴퓨터를 합니다. 청키 픽셀 (8px) + 굵은 검정
테두리 스타일이라 어떤 배경화면 위에서도 또렷하게 보여요. 내가 타이핑하면 펫도
콩콩 따라 치고, 뽀모도로를 완주하면 잔디가 쌓이고, 점수를 모아 레벨을 올리면
책상을 꾸미고 친구들과 랭킹을 겨룰 수 있습니다.

## 1. 설치

### macOS (Apple Silicon, M1 이상)

**Homebrew** (추천 — "손상됨" 경고 없이 설치돼요):

```bash
brew tap wooyerine/tap
brew trust wooyerine/tap   # 최신 Homebrew는 외부 tap을 한 번 신뢰해 줘야 해요
brew install --cask desktop-pet
```

또는 [Releases](https://github.com/wooyerine/desktop-pet/releases)에서 `.dmg`를
받아 `Desktop Pet.app`을 응용 프로그램에 드래그하세요.

> ⚠️ dmg로 설치하면 서명되지 않은 앱이라 처음 열 때 macOS가 **"손상되었기 때문에
> 열 수 없다"**며 차단해요 (실제 손상 아님). 터미널에서 아래 한 줄을 실행한 뒤
> 다시 여세요:
>
> ```bash
> xattr -cr "/Applications/Desktop Pet.app"
> ```

### Windows (x64)

`desktop-pet-setup-*.exe`를 받아 실행하면 바로 설치돼요.
서명이 없어서 SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.
키보드 감지에 별도 권한은 필요 없어요.

### 자동 업데이트

새 버전이 나오면 앱이 알려줘요 — Windows는 받아서 재시작하면 자동 설치되고,
macOS는 zip을 받아 앱을 직접 교체한 뒤 재시작합니다. 메뉴바 아이콘의
**업데이트 확인**으로 직접 확인할 수도 있어요.

## 2. 시작하기

### macOS 권한 (첫 실행)

**키보드 감지**에는 손쉬운 사용 권한이 필요합니다. 첫 실행 시 뜨는 프롬프트에서
허용하거나, 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 **Desktop Pet** 을 켠 뒤 앱을 재시작하세요. 권한이 없어도 마우스 움직임은
감지됩니다 (키보드만 감지 불가).

### 버튼 한눈에 보기

| 조작 | 동작 |
|---|---|
| 펫(캔버스) 드래그 | 창 위치 이동 |
| 💼 버튼 | 일 시작 / 일 끝 (세션 점수 정산) |
| ☕ 버튼 | 자리 비움 토글 (세션 중에만 표시) |
| ⏰ 버튼 | 타이머 패널 열기/닫기 |
| 🏆 버튼 | 랭킹 패널 (닉네임 등록 / 리더보드) |
| 🐾 버튼 | 펫 교체 (고양이 → 강아지 → 토끼 → 햄스터 → 해달) |
| 🌱 버튼 | 잔디밭 (집중 시간 16주 히트맵 / 연속 기록) |
| 메뉴바(트레이) 아이콘 | 크기 / 항상 맨 위 / 업데이트 / 게임 규칙 / 종료 |
| ✕ 버튼 | 앱 종료 |

창은 항상 위에 떠 있고, 모든 스페이스(전체화면 포함)에서 보이며, Dock에는
나타나지 않습니다.

## 3. 펫과 함께 지내기

펫은 내 입력을 실시간으로 따라 해요:

- ⌨️ 내가 키보드를 치면 펫도 앞발을 좌우 교대로 콩콩
- 🖱️ 내가 마우스를 움직이면 오른발이 마우스 위로 (둘 다 하면 왼발 키보드 + 오른발 마우스)
- 😴 1분 넘게 가만히 있으면 잠들어요 (Zzz)
- 💢 타이머를 안 쓸 때 키보드를 10분 이상 안 치면 "일해라 냥!" 잔소리 말풍선이
  떠요 (타이핑하면 사라짐)
- 🚶 일하는 중이 아닐 때 2분 넘게 자리를 비우면 펫이 책상에서 내려와 화면 맨
  아래 가장자리를 따라 작게 걸어 다녀요 — 고양이·강아지·햄스터는 네 발로,
  토끼는 깡총깡총, 해달은 두 발로 뒤뚱뒤뚱. 가끔 멈춰 서서 이쪽을 보고,
  아무 데서나 낮잠도 자요. 돌아다니는 동안엔 버튼이 숨고 클릭이 그대로
  통과되니 뒤쪽 앱을 쓰는 데 방해가 없어요. 키보드나 마우스를 건드리면
  책상으로 달려와 앉고, 일 시작·타이머 중에는 나가지 않아요
  (걸어 다닐 땐 액세서리가 안 보여요)

🐾 버튼으로 펫을 바꿀 수 있어요 — 회색 고양이 → 처진 귀 강아지 → 흰 토끼 →
골든 햄스터 → 해달 순환. 선택은 다음 실행에도 기억됩니다.

🌙 밤(20시~6시)에는 장면이 어두워지고 달이 떠요 — 무드등은 밤에 더 밝게 빛납니다.

🦋 일하는 중에 가끔 손님이 놀러 와요 — 무당벌레는 처음부터, 참새(Lv.10) →
달팽이(20) → 반딧불이(30, 밤에만) → 나비(42) 순으로 레벨이 오르면 새 손님이
늘어납니다. 만난 방문객은 업적 패널의 **도감**에 기록되고, 아직 못 만난 칸에
마우스를 올리면 몇 레벨부터 오는지 귀띔해 줘요.

## 4. 뽀모도로 타이머

⏰ 버튼으로 타이머 패널을 열어요.

- **집중 25분 / 휴식 5분 / 커스텀 (1~180분)**
- 타이머는 펫 머리 위 흰 픽셀 말풍선으로 표시돼요
- 완료하면 알림이 오고 펫이 폴짝폴짝 축하합니다
- 완주한 집중 세션은 [잔디밭](#5-잔디밭)에 쌓이고, 완주 보너스 점수도 받아요

---

## 5. 잔디밭

🌱 버튼을 누르면 완주한 **집중 시간(분)** 을 깃허브 잔디처럼 16주치로 보여줘요.

- **10분 이상** 세션만 심겨요
- 25분마다 색이 한 단계씩 진해져요 (100분부터 최고 단계)
- 깃허브가 어느 PC에서 커밋하든 합치듯, **데스크탑 50분 + 노트북 25분 =
  그날 75분**으로 여러 PC의 기록이 합산됩니다
- 가끔 펫이 안 물어봐도 자랑해요 — "12일 연속! 🔥"

## 6. 키우기 — 점수와 레벨

💼 버튼으로 일을 시작하면 점수가 쌓여요.

| 상황 | 점수 |
|---|---|
| 타이핑 (최근 10초에 키 3번 이상) | +1/초 |
| 잠들면 | -1/초 |
| 잔소리 뜨면 | -2/초 |
| 세션 완주 보너스 (10분 이상 + 순증가 세션만) | +50 |
| 뽀모도로 완주 | +100 |

- 한 번 톡 누르는 걸로는 점수가 안 쌓여요 — 진짜 타이핑 리듬에만 점수를 줍니다
- **레벨 업**은 레벨×1000점 — 오르면 펫이 폴짝폴짝!
- 점수가 바닥나면 레벨도 떨어져요 — "레벨 떨어졌다 TㅁT" (세션당 한 번, Lv.1이 바닥)
- ☕ 자리 비움을 켜면 점수 증감과 잔소리가 멈춰요
- 레벨/경험치는 저장됩니다

## 7. 꾸미기 · 업적 · 이벤트

### 🎨 꾸미기 (레벨로 해제)

레벨을 올리면 책상을 꾸밀 수 있어요:

| 종류 | 해제 순서 (레벨) |
|---|---|
| 책상 소품 | 해바라기씨 3 → 조개 5 → 군고구마 8 → 선풍기 12 → 화분 18 → 어항 27 → 무드등 36 → 곰인형 38 → 녹차 세트 48 → 라디오 57 → 책 더미 62 → 펭귄 인형 67 → 레트로 게임기 72 → 미니 기타 79 → 도넛 접시 84 → 수정구슬 92 → 괘종시계 96 |
| 액세서리 | 안경 6 → 헤드셋 10 → 목도리 13 → 선글라스 16 → 산타 모자 18 → 왕관 20 → 리본 40 → 실크햇 51 → 방울 목걸이 59 → 모노클 69 → 밀짚모자 76 → 클로버 핀 77 → 고글 82 → 유니콘 뿔 88 → 거꾸로 쓴 캡 94 → 가면 98 → 천사 링 100 |
| | **Lv.33**부터 겹쳐 착용 — 👁 눈 · 🧢 머리 · 🧣 목, 자리가 다르면 함께 (안경+목도리, 선글라스+헤드셋…) |
| 스킨 | 골드 25 → 딸기우유 30 → 흑요석 50 → 홀로그램 70 → 은하수 90 |
| 책상 | 원목 15 → 대리석 25 → 대나무 45 → 블랙 유리 65 → 구름 80 → 황금 100 |
| 키보드 | 기계식 22 → RGB 53 → 타자기 74 → 크리스탈 86 (타이핑하면 키가 눌려요) |

꾸미기 패널은 열린 것 + 다음 잠금 2개만 보여 주고 나머지는 「…+N」 칩 뒤에 접어 둡니다.

화분은 내 레벨이 오르면 새싹 → 수풀(30) → 꽃(42)으로 같이 자라고, 꽃이 핀
뒤에야 🦋 나비 손님이 찾아옵니다.

### 🏅 업적 (히든 소품)

- 뽀모도로 100회 → 🍅 토마토
- 30일 연속 잔디 → 🔥 미니 모닥불
- 새벽 5시 세션 → ☀️ 아침 해
- 리더보드 1위 → 🏆 트로피

업적·도감은 동기화 코드로 이어진 PC끼리 서버에서 합쳐집니다 (업적은 합집합,
횟수는 큰 쪽) — 어느 PC에서 달성했든 다른 PC에서도 열려 있어요.

### 🎃 계절 이벤트 (매년 반복)

- **9월**에 뽀모도로 20회 완주 → 👻 유령 스킨(반투명!) + 🎃 펌킨 조명
- **11월**에 뽀모도로 20회 완주 → ❄️ 아이스 스킨 + 🎄 크리스마스 트리 세트
- **4~5월** 두 달 동안 뽀모도로 20회 완주 → 🌸 벚꽃 스킨 + 🌸 벚꽃 화병

이벤트 달에 앱을 켜면 알려줍니다. 이벤트 아이템은 **시즌에만** 쓸 수 있어요 —
벚꽃은 4~5월, 유령·펌킨 조명은 9~10월, 아이스·트리는 11~12월. 철이 지나면 자동으로
치워지고(💤), 다음 해 시즌이 오면 미션 없이 바로 다시 꺼냅니다.

## 8. 랭킹

🏆 버튼에서 닉네임을 저장하면 Supabase 리더보드에 참가해요 — 친구들과 레벨 경쟁!

- 닉네임은 선착순 고유(대소문자 무시)라 남의 닉네임은 쓸 수 없어요
- 점수는 레벨 업 / 일 끝 / 일하는 중 5분마다 / 앱 종료 시 자동 업로드돼요
- 레벨 배지(⭐ Lv.10+ / 🌟 Lv.20+ / 💎 Lv.30+)가 닉네임 옆에 붙어요
- 리스트에는 상위 10명이 보이고, 내가 10위 밖이면 맨 아래 ⋯ 밑에 내 순위가
  한 줄 더 붙어요 (동점이면 공동 순위)

### 이번 주 / 전체 탭

- **이번 주**(기본): 이번 주에 **얻은 경험치**로 겨뤄요. 일요일 0시(한국 시간)에
  모두 0으로 리셋되니 늦게 시작해도 이번 주엔 1위가 될 수 있어요.
  잠들거나 잔소리로 깎인 만큼은 빠지지만 0 밑으로는 안 내려가요
- **전체**: 누적 레벨 순 (예전 랭킹 그대로)
- 주간 점수는 업로드 사이에 늘어난 경험치를 서버가 세요 — 그래서 일하는 중에는
  5분마다, 일을 끝내면 바로 반영돼요

### 💭 친구 책상 상상 (Lv.35+)

랭킹 줄을 클릭하면 펫이 그 친구의 책상을 구름 생각 풍선으로 상상해요.

- 상상 한 번에 **경험치 3,000 소모** (같은 친구는 5분간 무료)
- 처음엔 상상 못 하는 자리에 구멍이 숭숭 뚫려 있다가, **Lv.42**부터 액세서리,
  **Lv.50**부터 소품까지 보이고, **Lv.60**이 되면 구멍 없이 전부 보입니다

## 9. 여러 PC에서 이어 키우기

닉네임 등록 시 만들어지는 **동기화 코드**로 같은 펫을 여러 PC에서 키울 수 있어요.

1. 원래 PC: 랭킹 패널의 "**내 코드**"에서 코드를 보기/복사
2. 새 PC: "**다른 PC에서 이어하기**"에 코드 입력
3. 시작할 때 더 최근에 저장한 PC의 진행 상황을 자동으로 불러옵니다

> 🔒 코드는 비밀번호처럼 나만 알고 있어야 해요.

## 10. 메뉴바 설정

오른쪽 위 고양이 아이콘을 눌러요. 설정은 다음 실행에도 기억됩니다.

| 메뉴 | 설명 |
|---|---|
| 업데이트 확인 | 새 버전 확인 (버전 표시 아래) — 새 버전이 있으면 "업데이트 받기"로 바뀌어요 |
| 펫 크기 | 작게 / 보통 / 크게. 도트 한 칸의 크기만 바뀌어서 작게 해도 글씨는 그대로예요 (14인치 노트북엔 작게가 편해요) |
| 항상 맨 위 | 끄면 다른 창이 펫을 가릴 수 있어요 |
| 제자리로 | 펫을 화면 오른쪽 아래로 되돌려요 |
| 게임 규칙 | 점수 증감 / 보너스 / 레벨 / 잔디 규칙 요약 |
| 종료 | 앱 종료 |

창은 내용 높이에 딱 맞게 줄어들어서, 펫 아래 빈 공간이 뒤쪽 앱 클릭을 가로채지
않아요.

## 11. 문제 해결

### macOS: 업데이트 후 키보드 감지가 안 돼요

앱을 갈아끼우면 macOS가 기존 권한을 무효화할 수 있어요. 시스템 설정 →
개인정보 보호 및 보안 → 손쉬운 사용에서 **Desktop Pet(또는 Electron)을 껐다
켜거나, − 로 지운 뒤 + 로 다시 추가**하고 앱을 재시작하세요.

### macOS: "손상되었기 때문에 열 수 없다"

서명되지 않은 앱이라 뜨는 경고예요 (실제 손상 아님). [설치](#1-설치)의
`xattr` 명령을 실행하거나, Homebrew로 설치하면 이 경고 없이 열려요.

### Windows: SmartScreen 경고

**추가 정보 → 실행**을 누르면 됩니다.
