# 🐱 Desktop Pet — 픽셀 고양이 동료

데스크탑 화면 위에 떠 있는 큼직한 픽셀의 고양이. 뾰족 귀에 볼 털이 복슬한 회색
고양이가 정면으로 앉아 책상에서 같이 컴퓨터를 합니다. 청키 픽셀 (8px) + 굵은 검정
테두리 스타일이라 어떤 배경화면 위에서도 또렷하게 보여요. 책상 디오라마에 민트
화면 모니터, 키보드, 마우스, 층층이 아이스 커피(생크림+빨대+라떼층)까지 — 소품은
절반 크기 픽셀로 잘게 그려 한눈에 알아볼 수 있고, 타이머는 머리 위 흰 픽셀
말풍선으로 표시됩니다.

- ⌨️ 내가 키보드를 치면 펫도 앞발을 좌우 교대로 콩콩
- 🖱️ 내가 마우스를 움직이면 오른발이 마우스 위로 (둘 다 하면 왼발 키보드 + 오른발 마우스)
- 😴 1분 넘게 가만히 있으면 잠들어요 (Zzz)
- 💢 타이머를 안 쓸 때 키보드를 10분 이상 안 치면 "일해라 냥!" 잔소리 말풍선이 떠요 (타이핑하면 사라짐)
- 🍅 뽀모도로 타이머: 집중 25분 / 휴식 5분 / 커스텀(1~180분), 완료 시 알림 + 펫이 폴짝폴짝 축하
- 🌱 잔디밭: 완주한 **집중 시간(분)** 을 깃허브 잔디처럼 16주치로 쌓아 보여줘요.
  10분 이상 세션만 심기고, 25분마다 색이 한 단계씩 진해져요(100분부터 최고).
  깃허브가 어느 PC에서 커밋하든 합치듯, **데스크탑 50분 + 노트북 25분 = 그날 75분**으로
  합산됩니다. 가끔 펫이 안 물어봐도 자랑해요 — "12일 연속! 🔥"
- 🐾 펫 교체: 회색 고양이 → 처진 귀 강아지 → 흰 토끼 → 골든 햄스터 → 해달 순환,
  선택은 다음 실행에도 기억돼요
- 🎨 꾸미기: 레벨을 올리면 열려요 — 책상 소품(해바라기씨 Lv.3 → 조개 5 → 군고구마 8 →
  선풍기 12 → 화분 18 → 어항 27 → 무드등 36), 액세서리(안경 6 → 헤드셋 10 → 목도리 13 →
  선글라스 16 → 산타 모자 18 → 왕관 20), 스킨(골드 25 → 딸기우유 30 → 흑요석 50),
  책상(원목 15 → 대리석 25), 기계식 키보드(22 — 타이핑하면 키가 눌려요).
  화분은 내 레벨이 오르면 새싹 → 수풀(30) → 꽃(42)으로 같이 자라고,
  꽃이 핀 뒤에야 🦋 나비 손님이 찾아옵니다
- 🏅 업적: 뽀모도로 100회 → 🍅 토마토, 30일 연속 잔디 → 🔥 미니 모닥불,
  새벽 5시 세션 → ☀️ 아침 해, 리더보드 1위 → 🏆 트로피 같은 히든 소품이 열려요
- 🎃 계절 이벤트 (매년 반복): 9월에 뽀모도로 20회 완주하면 👻 유령 스킨(반투명!) +
  🎃 펌킨 조명, 11월에 20회 완주하면 ❄️ 아이스 스킨 + 🎄 크리스마스 트리 세트를
  받아요 — 이벤트 달에 앱을 켜면 알려줍니다
- 🦋 방문객 도감: 일하는 중에 가끔 나비/참새/무당벌레/달팽이/반딧불이(밤)가
  놀러 와요 — 만난 방문객은 업적 패널의 도감에 기록됩니다
- 🌙 밤(20시~6시)에는 장면이 어두워지고 달이 떠요 — 무드등은 밤에 더 밝게 빛납니다
- 🖥️ 메뉴바(오른쪽 위 고양이 아이콘)에서 조절해요 — 설정은 다음 실행에도 기억됩니다
  - **펫 크기**: 작게 / 보통 / 크게. 도트 한 칸의 크기만 바뀌어서 작게 해도 글씨는 그대로예요 (14인치 노트북엔 작게가 편해요)
  - **항상 맨 위**: 끄면 다른 창이 펫을 가릴 수 있어요
  - **제자리로**: 펫을 화면 오른쪽 아래로 되돌려요
  - **게임 규칙**: 점수 증감 / 보너스 / 레벨 / 잔디 규칙 요약을 보여줘요
  - 창은 내용 높이에 딱 맞게 줄어들어서, 펫 아래 빈 공간이 뒤쪽 앱 클릭을 가로채지 않아요
- 💼 키우기: 일 시작 후 타이핑하면 +1/초(최근 10초에 키 3번 이상 — 한 번 톡
  누르는 걸로는 점수가 안 쌓여요), 잠들면 -1/초, 잔소리 뜨면 -2/초.
  완주 보너스 +50은 10분 이상 + 순증가 세션에만, 뽀모도로 완주 +100.
  레벨 업(레벨×1000점)하면 펫이 폴짝폴짝!
  점수가 바닥나면 레벨도 떨어져요 — "레벨 떨어졌다 TㅁT" (세션당 한 번, Lv.1이 바닥)
  ☕ 자리 비움을 켜면 점수 증감과 잔소리가 멈춰요. 레벨/경험치는 저장됩니다
- 🏆 랭킹: 닉네임을 저장하면 Supabase 리더보드에 참가 — 친구들과 레벨 경쟁!
  닉네임은 선착순 고유(대소문자 무시)라 남의 닉네임은 쓸 수 없어요.
  점수는 레벨 업 / 일 끝 / 일하는 중 5분마다 / 앱 종료 시 자동 업로드돼요.
  레벨 배지(⭐ Lv.10+ / 🌟 Lv.20+ / 💎 Lv.30+)가 닉네임 옆에 붙어요.
  리스트에는 상위 10명이 보이고, 내가 10위 밖이면 맨 아래 ⋯ 밑에 내 순위가
  한 줄 더 붙어요 (동점이면 공동 순위).
  **Lv.35부터** 랭킹 줄을 클릭하면 펫이 그 친구의 책상을 구름 생각 풍선(💭)으로
  상상해요 — 상상 한 번에 **경험치 3,000을 소모**하고(같은 친구는 5분간 무료),
  처음엔 상상 못 하는 자리에 구멍이 숭숭 뚫려 있다가(42부터 액세서리,
  50부터 소품까지) **Lv.60**이 되면 구멍 없이 전부 보입니다
- 🔑 여러 PC에서 키우기: 닉네임 등록 시 만들어지는 **동기화 코드**(랭킹 패널의
  "내 코드"에서 보기/복사)를 다른 PC의 "다른 PC에서 이어하기"에 입력하면 같은
  펫을 이어서 키울 수 있어요. 시작할 때 더 최근에 저장한 PC의 진행 상황을
  자동으로 불러옵니다. 코드는 비밀번호처럼 나만 알고 있어야 해요

## 설치 (친구용)

[Releases](https://github.com/wooyerine/desktop-pet/releases)에서 받으세요.

- **macOS** (Apple Silicon, M1 이상): `.dmg`를 받아 `Desktop Pet.app`을 응용 프로그램에 드래그하면 끝이에요.

  > ⚠️ 서명되지 않은 앱이라 처음 열 때 macOS가 **"손상되었기 때문에 열 수 없다"**며
  > 차단해요 (실제 손상 아님). 터미널에서 아래 한 줄을 실행한 뒤 다시 여세요:
  >
  > ```bash
  > xattr -cr "/Applications/Desktop Pet.app"
  > ```

- **Windows** (x64): `desktop-pet-setup-*.exe`를 받아 실행하면 바로 설치돼요.
  서명이 없어서 SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.
  키보드 감지에 별도 권한은 필요 없어요.

설치 후에는 새 버전이 나오면 앱이 알려줘요 — Windows는 받아서 재시작하면
자동 설치되고, macOS는 zip을 받아 앱을 직접 교체한 뒤 재시작합니다.

## 개발용 실행

```bash
npm install
npm start
```

배포 파일 빌드는 `npm run dist`(macOS) / `npm run dist:win`(Windows, macOS에서도 빌드 가능).
결과물은 `dist/`에 생성됩니다.

## 릴리즈 절차

자동 업데이트가 GitHub 릴리즈를 피드로 쓰기 때문에 아래를 지켜야 해요:

1. `package.json` 버전 올리고 커밋, 태그는 반드시 `v버전` 형식 (예: `v1.8.0`)
2. `npm run dist && npm run dist:win`
3. 릴리즈에 산출물과 함께 **`latest-mac.yml`·`latest.yml`을 꼭 업로드**
   (이 두 파일이 업데이트 피드다 — 빠뜨리면 기존 유저가 새 버전을 모른다):

   ```bash
   gh release create v1.8.0 dist/desktop-pet-*.zip dist/desktop-pet-*.dmg \
     dist/desktop-pet-setup-*.exe dist/latest-mac.yml dist/latest.yml
   ```

   파일명에 공백이 생기면 안 돼요 — GitHub이 공백을 점으로 바꿔서
   yml 피드의 파일명과 어긋나 업데이트가 404로 실패합니다
   (그래서 artifactName을 공백 없이 고정해 뒀어요).

## macOS 권한

- **키보드 감지**에는 손쉬운 사용 권한이 필요합니다. 첫 실행 시 뜨는 프롬프트에서 허용하거나,
  시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 **Electron**을 켠 뒤 앱을 재시작하세요.
- 권한이 없어도 마우스 움직임은 커서 좌표 폴링으로 감지됩니다 (키보드만 감지 불가).
- **업데이트 후 키보드 감지가 안 되면**: 앱을 갈아끼우면 macOS가 기존 권한을 무효화할 수
  있어요. 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 **Desktop Pet(또는
  Electron)을 껐다 켜거나, − 로 지운 뒤 + 로 다시 추가**하고 앱을 재시작하세요.

## 사용법

| 조작 | 동작 |
|---|---|
| 펫(캔버스) 드래그 | 창 위치 이동 |
| 💼 버튼 | 일 시작 / 일 끝 (세션 점수 정산) |
| ☕ 버튼 | 자리 비움 토글 (세션 중에만 표시) |
| ⏰ 버튼 | 타이머 패널 열기/닫기 |
| 🏆 버튼 | 랭킹 패널 (닉네임 등록 / 리더보드) |
| 🐾 버튼 | 펫 교체 (고양이 → 강아지 → 토끼 → 햄스터 → 해달) |
| 🌱 버튼 | 잔디밭 (집중 시간 16주 히트맵 / 연속 기록) |
| 메뉴바(트레이) 아이콘 | 펫 크기 / 항상 맨 위 / 제자리로 / 게임 규칙 / 종료 |
| ✕ 버튼 | 앱 종료 |

창은 항상 위에 떠 있고, 모든 스페이스(전체화면 포함)에서 보이며, Dock에는 나타나지 않습니다.

## 구조

- `main.js` — 투명 창 생성, uiohook 전역 입력 감지(+커서 폴링 폴백), 알림
- `preload.js` — contextBridge IPC
- `pet.js` — 픽셀 아트 스프라이트, 애니메이션 상태 머신, 뽀모도로 타이머
- 펫은 행별 실루엣(`*_SIL`)과 색 영역(`*_PAINT`)으로 정의하고 검정 테두리를 자동
  생성합니다 — `PET_DEFS`에 실루엣/발/얼굴을 등록하면 새 동물을 추가할 수 있어요.
  눈/발/마우스/컵은 별도 스프라이트
- 동물을 추가할 땐 `PET_DEFS` / `PET_ORDER` / `PET_EMOJI`와 함께
  **`supabase.sql`의 허용 목록(`p_pet not in ...`)도 같이 늘려야** 해요.
  빠뜨리면 그 펫을 고른 사람만 점수 업로드가 조용히 막힙니다

### 리더보드 설정 (최초 1회)

Supabase 프로젝트의 **SQL Editor**에서 `supabase.sql`을 실행해 테이블을 만들어 주세요.
v1(기기별 등록) 테이블을 쓰고 있었다면 같은 스크립트를 다시 실행하면 v2(닉네임
계정 + 동기화 코드)로 마이그레이션됩니다 — 중복 닉네임은 최고 진행도 행만 남고,
기존 유저는 앱 업데이트 후 처음 실행할 때 자기 닉네임을 자동으로 이어받아요.
`pet.js` 상단의 `SB_URL` / `SB_KEY`를 자기 프로젝트 값으로 바꾸면 다른 그룹에서도 쓸 수 있어요.
publishable(anon) 키는 클라이언트 공개용이라 저장소에 넣어도 괜찮습니다 (권한은 RLS로 제어).

v6(꾸미기 동기화)부터는 `supabase.sql`을 **다시 실행**해야 `deco` 칼럼이 생겨요.
실행 전에도 앱은 정상 동작하지만(자동으로 한 단계 물러남), 꾸미기가 다른 PC와
동기화되려면 스키마를 갱신해야 합니다.

### 디버그

```bash
DEMO=typing npm start        # typing | mousing | sleeping | celebrating | sad | nag
PET=hamster npm start        # cat | dog | rabbit | hamster | otter
TIMER=25 npm start           # 타이머가 시작된 상태로 실행
PANEL=rank npm start         # rank | timer 패널이 열린 상태로 실행
SHOT=/tmp/pet.png npm start  # 1.2초 후 스크린샷 찍고 종료
```
